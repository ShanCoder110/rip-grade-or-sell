# pokemontcg.io / Pokémon TCG API — commercial use (Prompt 3)

**URL reviewed:** https://dev.pokemontcg.io/terms (Developer Portal Terms of Service for the Pokémon TCG API at `api.pokemontcg.io`).

**Note:** https://pokemontcg.io/terms returned 404 at review time. Documentation lives at https://docs.pokemontcg.io/.

**Commercial use:** The Developer Portal terms do not prohibit building commercial products on top of the API. They impose acceptable-use rules (one key per person/team, no key sharing or resale of accounts, no circumvention of rate limits) and disclaim liability for price data accuracy. They do not state a blanket “non-commercial only” restriction.

**Related (successor API):** https://pokemontcgapi.com/legal/terms explicitly allows commercial products with attribution, while prohibiting redistribution of raw price observations as a competing dataset.
